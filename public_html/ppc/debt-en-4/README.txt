Debt Relief Landing Page
==========================

Files:
- index.php: responsive PHP landing page
- assets/style.css: page styling
- assets/hero.jpg: cropped hero image based on the supplied reference
- assets/reference.png: original uploaded reference image

Setup:
1. Upload the folder to a PHP-enabled hosting account.
2. Keep the assets folder beside index.php.
3. Change $phone and $phoneHref at the top of index.php if the campaign phone number changes.
4. Replace the hero image if you have a licensed/original creative asset.

Compliance note:
The page intentionally avoids presenting the offer as a government program and includes a disclosure that eligibility is not guaranteed.
